AI Agent

vibeMusicians — Autonomous Agent Pipeline

A six-stage AI agent pipeline that researches music trends, invents an artist persona, writes a song, generates audio and cover art, and publishes to SoundCloud. Built on the Anthropic Messages API with bounded web search for cost control, JSON-schema structured outputs, per-stage SQLite checkpointing for crash-safe resume, and OAuth 2.1 rotating refresh tokens persisted across ephemeral CI runs.

Result: ran unattended on a GitHub Actions cron and published 26 original tracks in about two weeks.

Python · Anthropic API · pydantic · SQLite · GitHub Actions

AI Agent

ai-assistant — Local Claude Agent with RAG

A local Claude agent with a twelve-tool function-calling loop. RAG over personal documents using 800-word chunks with overlap, a persistent ChromaDB store with all-MiniLM-L6-v2 embeddings, dedup on re-indexing and relevance-ranked retrieval. Integrates Google Calendar and Gmail over OAuth2, PDF question answering and local Whisper speech-to-text.

Result: one assistant that answers from your own files, calendar and inbox, running locally.

Python · Anthropic API · ChromaDB · RAG · Whisper
